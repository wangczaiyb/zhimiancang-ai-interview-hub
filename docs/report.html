一、项目背景与命题解读

当前就业竞争加剧，大学生面临双重困境：毕业生面试易受紧张情绪影响， 难以展现真实水平；新生因不了解企业需求，专业学习缺乏针对性。与此同时，企业端传统招聘初筛 效率低、成本高，人岗匹配精准度不足。

本命题要求搭建高度还原企业真实场景的模拟面试平台，实现双向赋能： 一方面帮助毕业生熟悉流程、克服紧张、从容展现优势；另一方面助力新生前置洞察用人标准， 明确学习方向与职业规划；同时为企业提供岗位模拟数据与综合表现分析，辅助高效筛选适配人才。

命题目标拆解

二、需求分析

我们把命题中的痛点收敛为三类核心用户，逐一定位问题与对策。

群体 A · 新生

职场规划与能力储备迷茫

对岗位要求与发展路径认知模糊，学习储备缺乏针对性，不知道"学什么、为什么学"。

对策：岗位画像可视化 + 低门槛体验面试 + 逐题知识点反馈， 让新生在入学初期就看清岗位技能清单。
群体 B · 毕业生

面试训练不足、临场发挥不佳

缺乏真实场景训练，紧张导致表达混乱，难以精准展现自身能力与岗位匹配度。

对策：全流程模拟 + 倒计时压力 + 提交即得诊断反馈 + 同一学号多次训练沉淀成长曲线，量化进步。
群体 C · 企业

初筛效率低、人岗匹配粗放

传统招聘筛选成本高、流程繁琐，难在短时间内判断候选人与岗位的真实契合度。

对策：人岗匹配度评分 + 岗位候选人排行榜 + 五维能力画像，把"筛简历"变成"看数据"。

三、解决方案总览

系统以"一次模拟面试"为主线，把学生的训练行为转化为企业的可筛选数据，形成闭环。

四、系统架构

采用前后端分离 + 分层后端架构，四层职责清晰，全部能力打包在单进程内， 通过 python main.py 一条命令启动，无中间件与外部服务依赖。

数据层：SQLite 单文件（data/interview.db），6 张表构成 「岗位 — 题库 — 候选人 — 面试 — 作答 — 评分」完整链路。选择单文件数据库是为了让作品 免安装、免配置、可整体拷贝，评审老师下载即可运行。

七、核心技术方案

7.1 结构化评分引擎（可解释）

评分不采用"黑箱打分"，而是拆成四个可解释分项，每一项都能向学生明确解释扣分原因。

7.2 双通道评分与自动降级

为什么这样设计？

  • 竞赛演示环境不确定：可能无网络、无 API Key。规则通道保证功能 100% 可用。
  • 可插拔增强：配置 LLM_ENABLED=1 与 API 地址后自动切换到大模型深度评分， 语义理解与反馈质量更高。
  • 故障不扩散：LLM 调用任一异常（网络/鉴权/超时/返回格式错误）都会回落到规则通道， 主链路不受影响。
  • 状态可观测：GET /api/channel 可查询当前通道与降级原因。

7.3 人岗匹配度算法

人岗匹配度 = 60% × 综合得分 + 40% × 岗位技能关键词命中率

技能命中率体现"回答内容是否真正覆盖企业要求的技能点"，这是企业端最关心的筛选信号。 综合得分反映面试表现，两者加权避免"答得好但不匹配岗位"的误判。

7.4 组卷策略

按 专业题 50% : 通用题 30% : 压力题 20% 的配比自动抽题。某类题库不足时自动从其余题目补足， 去重后打乱顺序；卷面以 JSON 固化在会话记录中，保证历史记录可复现（即使题库后续被编辑）。

九、成果亮点

1

三类题型 × 五维模型，还原真实面试

专业题 / 通用题 / 压力题按 5:3:2 组卷，覆盖知识、表达、心态三层考察； 输出专业技能、表达逻辑、抗压能力、学习潜力、岗位认知五维画像。

2

双通道评分，离线可用、在线更优

规则引擎保证任何环境 100% 可运行；配置大模型后自动切换深度语义评分， 故障自动降级，兼容不同院校的算力与预算条件。

3

即时反馈 + 成长曲线，训练闭环

每题提交即得诊断反馈与参考答案；同一学号多次训练沉淀成长曲线， 让"进步"从感觉变成数据。

4

人岗匹配度，直击企业筛选痛点

综合表现（60%）+ 岗位技能命中率（40%）加权，输出可排序的候选人榜单， 把"筛简历"变成"看数据"。

5

零依赖、一键启动、易推广

仅 3 个纯 pip 依赖 + SQLite 单文件，无 CDN、无构建步骤， python main.py 即可运行，便于在兄弟院校快速复制。

6

可解释评分，服务教学改进

评分拆为四个可解释分项，逐题指出知识盲区与表达问题， 教师可据此调整教学重点，形成"测—评—教"闭环。

十、应用场景与落地可行性

院校就业指导中心

作为面试实训工具纳入就业指导课程， 批量组织模拟面试，用数据识别需要重点帮扶的学生。

校企合作招聘

企业发布真实岗位画像，学生在校即可完成初筛演练， 企业提前锁定高匹配人才，缩短招聘周期。

专业建设参考

岗位技能命中率数据反向反映课程体系与产业需求的差距， 为人才培养方案修订提供量化依据。

落地可行性：系统为纯软件方案，无需专用硬件；可与校园网、实训平台直接集成。 后续可对接学校统一身份认证与教务系统，实现课程—训练—就业数据贯通。

十一、总结与展望

本项目围绕命题 05「智能面试仓的开发与应用」，完成了从需求分析、架构设计、 核心开发到测试验证的完整闭环，交付了一套可运行、可演示、可推广的模拟面试平台。

系统以"学生训练 × 企业筛选"双向闭环为核心，用结构化题库与可解释评分让学生的每一次练习 都有明确反馈，用人岗匹配度与能力画像让企业的每一次筛选都有数据支撑， 切实回应了命题中"打通教学与产业壁垒"的诉求。
